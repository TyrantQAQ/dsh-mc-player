# MC 玩家插件 · 设计文档

写给接下来写代码的那个我。先读这一份，再动手。

---

## 一句话目标

让 AI 像**一个真实玩家**那样在 Minecraft Java 版里活着：会走会跳会怕，会自己定目标，会犯错也会自救；做完事能拿出证据，而不是说"应该做好了"。

## 为什么不用现成的

看过 `whale-craft`、`dsh-mc-agent` 两个。它们把每个动作做成一次工具调用，调用结束才把结果交给模型。问题有三个：

1. **模型在动作期间是瞎的。** 挖矿调用要跑十秒，这十秒里僵尸来了它不知道。
2. **每次都很准，反而不像人。** 它们追求"成功率高"，但真人会挖歪、会跳空、会犹豫。
3. **只做事，不过日子。** 没有"今天想干什么"，只有"你让我干什么"。

所以这个插件重写，核心是把**反射**和**判断**分开。

## 架构：小脑 + 大脑

```
┌─────────────────────────────────────────┐
│ 大脑（DSH agent / LLM，秒级）            │
│  决定：打不打、去哪、盖什么、今天做什么  │
└───────────────┬─────────────────────────┘
                │ 工具调用（一个动作）
┌───────────────▼─────────────────────────┐
│ 小脑（插件进程，每 tick 20Hz）           │
│  反射：危险后退 / 吃 / 上浮 / 瞄准 / 节奏 │
│  感知：位置 / 血 / 氧气 / 实体 / 声音     │
│  动作：执行 + 分段返回进度                │
│  事件：攒着，大脑醒来时一起给             │
└───────────────┬─────────────────────────┘
                │ mineflayer
┌───────────────▼─────────────────────────┐
│ Minecraft 服务器                          │
└─────────────────────────────────────────┘
```

**小脑不替大脑做决定，只保命。** 它只做这几件：血太低吃东西、苦力怕贴脸后退、掉进岩浆上浮、氧气快没浮上去、被围住停手。其余一律上报，不擅自行动。

**大脑不要求实时。** 它几秒看一次，看的是小脑整理好的现状，不是原始数据。

## 能力清单

### 一、身体：动作

**移动**
走、疾跑、跳、潜行（边缘不掉）、游泳、上浮、下沉、爬梯子/藤蔓/脚手架、跳一格、搭柱子、边跳边铺路、坐船、坐矿车、骑马/猪、落地放水桶。

**手**
- 挖：不同方块耗时不同，工具影响速度，耐久会掉
- 放：对方块右键，潜行时不触发交互
- 用：门、按钮、拉杆、压力板、活板门
- 长按：吃、拉弓、喝药、举盾、钓鱼
- 对生物右键：喂食、繁殖、交易、剪羊毛、挤奶、骑乘
- 丢东西、切快捷栏、换副手

**界面**
开背包、开箱子/桶/潜影盒、开熔炉/高炉/烟熏炉、开工作台、开附魔台、开铁砧、开酿造台、村民交易界面、开聊天框、开指令、死亡界面重生。

⚠️ 这块最容易漏。**开着界面时走不了路；开着聊天框时 WASD 会变成打字。** 插件必须让模型知道"我现在在哪个界面"，并且能主动关掉。

**功能方块**
工作台（3×3 合成）、熔炉类（烧炼）、铁砧（修理/改名/合附魔）、附魔台（配书架）、酿造台（药水）、村民交易、信标、箱子、唱片机、音符盒、红石（发射器、活塞、观察者）。

**睡觉**
晚上或雷雨、床没被占、周围没怪 → 躺下过夜、设重生点；被打断会醒。

**指令**
`/tp` `/give` `/time` `/weather` `/gamemode` `/effect` `/summon` `/kill` `/fill`。
知道什么时候该用、什么时候用了就是作弊。

### 二、感官：感知

**自己**：位置、朝向（yaw/pitch）、血量、饥饿、氧气、经验等级、状态效果（中毒/缓慢/失明/夜视/抗火）、手里拿的、身上穿的、背包内容。

**世界**：时间、天气、维度、脚下是什么方块、头顶封没封、能不能站、附近有没有水/岩浆/悬崖/掉落物。

**声音**：怪叫、爆炸、脚步、雨。真人一半的信息是听来的。mineflayer 有 `soundEffectHeard` 事件，把它接进来，按方位和类型报。

**手感**：跑多快、跳多高、摔下来掉多少血、水里多慢。这些数字决定"我敢不敢跳"。

### 三、脑子：像玩家一样想

- **知道自己现在能不能被打断**（开着界面 / 正在拉弓 / 正在吃）
- **会换工具**：空手挖石头慢，自己换镐
- **会累、会换事做**：挖矿久了会烦
- **记得路**：家在哪、矿洞口在哪、上次死在哪（本地地图文件）
- **会怕**：血少不打、天黑回家、听见苦力怕就退
- **自己定目标**：今天挖到钻石、把这间屋子盖完
- **会失误也会自救**：挖错、放歪、跳空、掉坑，然后爬出来
- **有节奏**：会停下来张望、犹豫、看一会儿
- **对看见的东西有反应**：远处有建筑会过去看看
- **操作不完美**：每次都太准反而不像人

## 三个关键机制

### 1. 实时性：反射层

每 tick（50ms）检查一次，命中条件立刻执行，**不等模型**：

| 条件 | 动作 |
|---|---|
| 苦力怕 ≤4 格 | 停手 + 后退 0.7 秒 + 举盾（有的话） |
| 血 ≤6 | 吃最好的食物 |
| 掉进岩浆 | 立刻上浮 / 放水 |
| 氧气 ≤8 | 上浮 |
| 头卡进方块 | 挪开 |
| 被 ≥3 只围 | 停手，报事件 |

**必须能中断正在进行的动作。** 动作执行器要支持 `abort`，反射层触发时推一个中断信号。

### 2. 验证：每个动作都要回读

不许"我记得"：

- 挖完 → 看那块是不是变成空气，背包有没有多东西
- 放完 → 看那格是不是变成了目标方块
- 合成完 → 看背包里有没有这个物品
- 走完 → 看位置是不是到了（`distance < 0.5`）

工具返回里必须有 `verified: true/false` 和证据（坐标、背包数量、扫描结果）。

### 3. 施工：图纸 + 验收

盖房子分三步：

1. **出图纸**：尺寸、层数、墙、门、窗 → 坐标表 `{x,y,z: block}`
2. **算料**：按图纸算出每种材料数量，去背包数，不够就采
3. **施工**：逐层放，每层扫一遍核对
4. **竣工验收**：整栋扫一遍，跟图纸逐格比，差几格、错几格，列出来

中途出事（天黑/来怪/材料不够）→ 存进度（图纸 + 已完成部分），下次接着来。

## 分期

### 一期：能活着（必须先做完）

- 连接：离线账号、地址+端口、断线重连
- 感知：完整状态快照（`mc_status`）
- 反射层：六个保命动作
- 移动：走、跑、跳、潜行、游泳
- 手：挖、放、用
- 生存：吃、睡
- 验证：每个动作回读
- 事件：攒着，下次调用时一起给

**一期验收**：在生存模式活过一晚，挖到 20 块石头，背包里真有。

### 二期：能干活

- 合成（工作台 3×3、背包 2×2）
- 容器（箱子存取、熔炉烧炼）
- 功能方块（附魔台、铁砧、酿造台、村民交易）
- 建筑（图纸 → 施工 → 验收）
- 种地、钓鱼、驯养
- 死亡与重生（记得掉在哪）

**二期验收**：从零盖一间 5×5×3 的小屋，竣工扫描 100% 匹配图纸；材料是现采的，全程有回读。

### 三期：像玩家

- 声音感知
- 自主目标（"今天干什么"）
- 地图记忆（家、矿洞、死亡点）
- 节奏（会停、会看、会犹豫）
- 模拟失误（小概率出错）
- 战斗策略（威胁排序、放风筝、收手）

**三期验收**：给它一句话"去弄点铁回来"，它能自己规划、出门、挖、回来，中途遇到怪会处理，回来拿出证据。

## 技术约束

- Node 22+，mineflayer（含 pathfinder / collectblock / tool / pvp / auto-eat）
- 运行环境：macOS（M1，8G），DSH 桌面版 0.2.1-rc.3
- 一个 bot 一个进程，不跟别的插件抢同一个账号
- 断线要能重连，重连后状态要重新拉一遍
- 崩了不能把 DSH 带走（未捕获异常必须兜住）

## 可以参考的

- `blueziii/dsh-mc-agent`：反射层、寻路补丁、结果回读的实现（读它的 CHANGELOG 能省很多坑）

## 给写代码的我

- 先做一期，别一上来就写全。
- 每个动作都要有 `verified`，没有证据的"成功"一律当失败。
- 反射层要能被测试：写一个假 bot，喂它"苦力怕在 4 格"，看它退不退。
- 别追求完美操作——真实玩家会失误，插件也该允许自己失误，但要能从失误里恢复。
